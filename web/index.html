Devices

    Saving rewrites config/device.json and keeps the previous version as device.json.bak. The running simulation is not affected until you restart it. Restarting re-reads the file and resets state of charge, energy counters and the simulated clock.

    Reads and writes go through the same devices_data table as the Modbus server on port 5021. A setpoint written here is identical to a function-code-16 write.
